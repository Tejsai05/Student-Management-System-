# 🎓 Student Management System

The **Student Management System** is a full-stack web application developed as part of technical training to demonstrate modern web application development using **Java Spring Boot** and **React.js**. The application provides an efficient way to manage student records through a user-friendly interface and a robust RESTful backend.

The backend is built using **Spring Boot**, **Spring Data JPA**, and **Hibernate**, exposing REST APIs for performing CRUD operations and advanced database functionalities such as searching, sorting, filtering, and batch updates. Student information is stored using an **H2 Database**, making the application lightweight and easy to set up for development and demonstration purposes.

The frontend is developed using **React.js** and communicates with the backend through REST APIs using **Axios**, providing a responsive and interactive user experience.

For deployment, the backend has been **containerized using Docker** and deployed on **Render**, while the frontend is hosted on **Vercel**, enabling the application to be accessed online without requiring a local setup.

This project demonstrates practical knowledge of:
- Java Spring Boot
- Spring Data JPA & Hibernate
- RESTful API Development
- React.js
- Axios
- H2 Database
- Docker Containerization
- Render Deployment
- Vercel Deployment
- Git & GitHub

The project follows a layered architecture with separate Controller, Service, Repository, and Entity layers, ensuring clean code organization, scalability, and maintainability. It serves as a practical example of building, containerizing, and deploying a modern full-stack application using industry-standard technologies.
